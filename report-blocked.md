# M3: реализация остановлена из-за ограничения области изменений

Дата: 2026-09-07. Ветка: `m3-config-guard`. Исходный коммит: `f1cc61a`.

Спецификация прочитана целиком. Реализация не начата: применяется раздел
«Контракт на невыполнимое», требующий остановиться при дефекте самой спеки.

## Что не сходится

Строки 35–38 и 55–56 требуют новый пакет подкоманды с
`NewCmd(cfg *static.Configuration, loaders []cli.ResourceLoader)` и регистрацию
в `cmd/traefik/traefik.go` рядом с `healthcheck`, с тем же массивом `loaders`.
При этом строки 109–110 разрешают в этом файле только «одну строку регистрации».

В существующем блоке импортов `traefik.go` нет нового пакета. Обычная реализация
потребует как минимум двух отдельных изменений в этом файле:

```go
// В блоке import:
"github.com/traefik/traefik/v3/cmd/validatecsr"

// В main, рядом с healthcheck:
err = cmdTraefik.AddCommand(validatecsr.NewCmd(&tConfig.Configuration, loaders))
```

Для обработки ошибки AddCommand по существующему образцу потребуется также
блок `if err != nil`. Импорт нельзя разместить внутри `main` в строке регистрации.
Добавление другого файла в `cmd/traefik/` тоже выходит за разрешённую область.
Считать импорт неявным исключением означало бы самостоятельно расширить явно
заданный список разрешённых изменений. Спецификация запрещает обход и поручает
исправление её дефектов координатору.

## Команда-доказательство

```sh
sed -n '35,38p;53,56p;103,110p' docs/specs/m3-config-guard.md && sed -n '17,52p;71,81p' .upstream/traefik/cmd/traefik/traefik.go
```

Команда выполнена, код 0. Она показывает конфликтующие требования, существующие
импорты и образец регистрации. Это доказательство ограничения спецификации,
а не заявление об ошибке компиляции или о провале выполненных тестов.

## Варианты для координатора

1. Разрешить в `cmd/traefik/traefik.go` импорт нового пакета и блок регистрации
   с обработкой ошибки рядом с `healthcheck`. Это минимальная правка спецификации,
   сохраняющая заданную архитектуру и общую цепочку загрузчиков.
2. Разрешить дополнительный файл в `cmd/traefik/` для импорта и вспомогательной
   функции регистрации, оставив одну строку вызова в `traefik.go`. Это более
   широкое исключение и лишняя косвенность; предпочтителен первый вариант.

а `rc: null` обозначает отсутствие запуска, а не выдуманный код возврата.
Дословной строки отказа для AC-007, AC-009 и AC-010 нет: гвард не реализован.

Файлы спецификаций не изменялись. Пуш не выполнялся и remote не менялся,
как прямо требует задача. Отчёты предназначены для передачи координатору.
